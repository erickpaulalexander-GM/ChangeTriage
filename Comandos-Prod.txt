Change Triage - comandos manuales para la PC del banco (prod)
==============================================================
Pegar linea por linea en cmd o PowerShell. Sirve cuando el .ps1 esta
bloqueado por politica. Requiere Python instalado (launcher 'py').

MODO OFFLINE: en la PC del banco NO hay que descargar nada en cada corrida.
run.bat nunca descarga: depende de que openpyxl/tzdata/pytest esten ya
instalados en el Python del launcher 'py'. Hay dos vias para lograrlo:

VIA A (sin USB, recomendada si ya tenes uv instalado):
  uv instala los 3 paquetes EN el Python del sistema, una sola vez.
  --system-certs usa el almacen de certificados de Windows (necesario
  porque el proxy del banco re-firma TLS con certificado interno).

  py -m uv pip install --system-certs openpyxl tzdata pytest
  py -c "import openpyxl, tzdata, pytest; print('deps OK')"

VIA B (USB, si algun dia tenes la carpeta wheels):
  py -m pip install --no-index --find-links wheels openpyxl tzdata pytest
  py -m pytest --version
  py -c "import openpyxl, tzdata, pytest; print('deps OK')"

(Cerrar y reabrir la terminal para que tome el PATH. Repetir VIA A o VIA B.)

[6] Correr el pipeline desde la raiz del repo:
run.bat

Nota: antes de [6], el workbook ControlPases.xlsx debe estar en la
carpeta input configurada (ver config.yaml).

Si VIA A falla por red (proxy/politica del banco), probar:
  py -m uv pip install --system-certs openpyxl
  py -m uv pip install --system-certs tzdata
  py -m uv pip install --system-certs pytest
(linea por linea; si una falla, se ve cual paquete/qué red falta).
