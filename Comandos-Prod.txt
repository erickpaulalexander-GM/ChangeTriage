Change Triage - comandos manuales para la PC del banco (prod)
==============================================================
Pegar linea por linea en cmd o PowerShell. Sirve cuando el .ps1 esta
bloqueado por politica. Requiere Python instalado (launcher 'py').

MODO OFFLINE: en la PC del banco NO hay que descargar nada en cada corrida.
run.py nunca descarga: depende de que openpyxl/tzdata/pytest esten ya
instalados en el Python del sistema al que apunta el launcher 'py'.
El banco bloqueo uv, asi que no se usa para nada (ni para instalar ni para
correr). Si falta algun paquete, corre el verificador de abajo.

VERIFICAR (una sola vez, sin instalar nada):
  py -c "import openpyxl, tzdata, pytest; print('deps OK')"
Si imprime "deps OK", no tenes que hacer nada mas. Si tira ModuleNotFoundError,
instalalo UNA vez con pip (unica via soportada, requiere red/proxy):
  py -m pip install -r requirements.txt
  py -c "import openpyxl, tzdata, pytest; print('deps OK')"
  py -m pytest --version

Si la red/proxy bloquea la descarga de PyPI, pide al area de TI que
instale los tres paquetes por TI. No hay carpeta 'wheels' en esta PC:
esta ignorada por git a proposito, asi que nunca llega al banco.

[0] Verificar el launcher de Python:
py --version
python --version

[4] Node.js (opcional, solo para el smoke de frontend):
node --version
winget install --exact --silent --accept-source-agreements --accept-package-agreements OpenJS.NodeJS.LTS

[5] Si falta Python:
winget install --exact --silent --accept-source-agreements --accept-package-agreements Python.Python.3.12
(Cerrar y reabrir la terminal para que tome el PATH. Luego repetir la
verificacion de dependencias de arriba.)

[6] Correr el pipeline desde la raiz del repo:
py run.py
(Sin pruebas, para produccion: py run.py --skip-tests)

Nota: antes de [6], el workbook ControlPases.xlsx debe estar DIRECTO en la
carpeta input configurada (ver config.yaml; en prod es ...\iTop).
