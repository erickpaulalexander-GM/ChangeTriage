Change Triage - comandos manuales para la PC del banco (prod)
==============================================================
Pegar linea por linea en cmd o PowerShell. Sirve cuando el .ps1 esta
bloqueado por politica. Requiere Python instalado (launcher 'py').

MODO OFFLINE: en la PC del banco NO hay descargas de internet.
Los paquetes openpyxl/tzdata/pytest se instalan UNA VEZ desde la
carpeta local 'wheels' (traida por USB). run.bat nunca descarga nada:
depende de que estos paquetes ya esten instalados en 'py'.

[0] Verificar el launcher de Python:
py --version
python --version

[1] Copiar la carpeta 'wheels' (con los .whl) a la raiz del repo.
    Debe quedar: <repo>\wheels\*.whl

[2] Instalar las dependencias UNA sola vez (offline, sin internet):
py -m pip install --no-index --find-links wheels openpyxl tzdata pytest
py -m pytest --version

[3] Verificar que abren (deben importar sin error):
py -c "import openpyxl, tzdata, pytest; print('deps OK')"

[4] Node.js (opcional, solo para el smoke de frontend):
node --version
winget install --exact --silent --accept-source-agreements --accept-package-agreements OpenJS.NodeJS.LTS

[5] Si falta Python:
winget install --exact --silent --accept-source-agreements --accept-package-agreements Python.Python.3.12
(Cerrar y reabrir la terminal para que tome el PATH. Repetir [2] y [3].)

[6] Correr el pipeline desde la raiz del repo:
run.bat

Nota: antes de [6], el workbook ControlPases.xlsx debe estar en la
carpeta input configurada (ver config.yaml).

Si algun wheel falta en 'wheels', la instalacion offline falla con un
mensaje que nombra el paquete; trae ese .whl (se generan con:
  pip download openpyxl tzdata pytest --dest wheels
en una maquina con internet) y reintenta [2].
